Spine on the left holds the actual transcript — host prompts (warm cards with serif quote marks), Claude responses (prose with inline code), tool calls (Read / Write / Bash with collapsible bodies), and GitHub events (quiet dashed cards). Right column is sticky-note chat; each note tilts a degree or two, gets the author’s color, and connects back to its anchor turn via a dashed leader line. Reactions stack under every transcript item. The "K here" / "M here" pins float next to whichever turn each watcher is currently looking at.

Why this works
  • Every type of thing — prompt, response, tool call, file edit, GH event — lives in one chronological spine, so a watcher who joins late just scrolls up
  • Sticky notes feel social (offset, color-coded, leader-lined) without overwhelming the actual transcript
  • Reactions are zero-friction and persistent — "this is the moment we all approved" is recoverable later
  • "Seen-by" ribbons quietly answer "did anyone notice?" without needing read-receipts UX
  • Light GH refs stay light: branch / commit / PR are dashed-card events, not their own surface
Watch out for
  • Long sessions = long scroll — needs a "filter to file changes only" toggle and a turn-id jumper
  • Sticky notes need a flat search/list view too, since stickies aren’t scannable past ~30 of them
  • Live cursor position over Cloudflare quick-tunnel will lag 200–500ms — the pin says "here" not "exactly here"
  • Author colors max out at ~6 watchers before they collide with each other or with state colors

What's new vs. mockup 03 (round table)

Round-table treated comments as inline replies under their anchor item. This version pulls them out into a parallel sticky-note column, keeps them visually distinct from the transcript, and adds reactions on every spine item. Tool calls now show real Claude Code tool shapes (Read, Write, Bash) with their typical inputs/outputs, so the actual conversation is legible rather than abstracted.

What's new vs. mockup 02 (whiteboard)

Whiteboard floated stickies on a 2D canvas around a single diff. This version anchors them to a vertical timeline so the spine is always navigable. Reactions and "seen-by" ribbons replace the line-level emoji clusters — same affordance, less density.
